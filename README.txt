Preview locally:
1. Keep index.html and the assets folder together.
2. Open index.html in a web browser.

Publish using GitHub Pages:
1. Extract this ZIP file.
2. Upload index.html and the complete assets folder to the root of your GitHub repository.
3. Ensure the image file is named exactly rakshan.jpg inside the lowercase assets folder.
4. Commit the changes to the branch configured for GitHub Pages.
5. Wait for deployment, then hard-refresh the website (Ctrl+Shift+R).
